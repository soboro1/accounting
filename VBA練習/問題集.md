# Excel VBA 練習問題集（全20問）

使うファイル: `サンプルデータ.xlsx` / `データ/売上_*.csv`

**進め方**
1. `サンプルデータ.xlsx` を開き、**「Excel マクロ有効ブック (.xlsm)」で別名保存**する（.xlsx のままだとマクロを保存できません）
2. `Alt + F11`（Mac は `Option + F11`）で VBE を開く
3. `挿入 > 標準モジュール` でモジュールを追加し、先頭に `Option Explicit` と書く
4. 自分で書いてみる → 詰まったら `解答例/` を見る
5. `F8` で1行ずつ実行（ステップ実行）すると、何が起きているか目で追えます

## シート構成

| シート | 内容 | 行数 |
|---|---|---|
| 商品マスタ | 商品コード・商品名・カテゴリ・単価 | 15 |
| 社員名簿 | 社員番号・氏名・支店・部署・役職・入社日・基本給 | 40 |

| 集計結果 | 練習の出力先（自由に使ってよい空シート） | – |

`データ/` には支店別の CSV が5本入っています（Lv5 で使用）。

# Lv1 基礎 — VBE に慣れる

### Q1. マクロの記録を読む ★
`開発 > マクロの記録` を押した状態で、売上明細の見出し行に色を付け、A列の幅を変えて、記録を停止する。
そのあと VBE で生成されたコードを開いて読む。

- 何行のコードになったか
- `Select` と `Selection` が大量に出てくるはず。**これを使わずに書き直す**とどうなるか考える

> 記録マクロは「Excel の操作 → VBA の対応表」を教えてくれる最高の教材です。ただし冗長なので、必ず手で書き直す癖をつけてください。

### Q2. 行数を表示する ★
「売上明細」シートのデータ行数（見出しを除く）を `MsgBox` で表示するマクロを書く。

- ヒント: `Cells(Rows.Count, "A").End(xlUp).Row` が「A列の最終行」

### Q3. セルに書き込む ★
「集計結果」シートの A1 に `作成日`、B1 に今日の日付、A2 に `作成者`、B2 に自分の名前を書き込む。
A列を太字にし、列幅を自動調整する。

- ヒント: `Date` / `Application.UserName` / `.Font.Bold` / `.AutoFit`

### Q4. 変数を使って計算する ★
売上明細の2行目の「単価」と「数量」を変数に取り出し、金額と税込金額（10%）を計算して MsgBox で表示する。

- ヒント: 整数は `Long`、小数が出るものは `Double`。`Dim` と `Option Explicit` に慣れること

# Lv2 制御構文 — 条件分岐とループ

### Q5. If で在庫を判定する ★★
「在庫」シートの G列「判定」に次を入れる。

| 条件 | 表示 |
|---|---|
| 在庫数 = 0 | 欠品 |
| 在庫数 ≦ 発注点 | 要発注 |
| それ以外 | OK |

さらに、欠品は赤字、要発注はオレンジ字、OK は緑字にする。

- ヒント: `If / ElseIf / Else / End If`、`.Font.Color = RGB(192, 0, 0)`

### Q6. For で合計を求める ★★
売上明細の K列「金額」をループで合計し、`WorksheetFunction.Sum` の結果と一致するか検算する。

- ヒント: 合計を入れる変数は `Long` だと桁あふれの危険。`Currency` か `Double` を使う

### Q7. Do While で走査する ★★
`Do While` を使って、A列が空になるまで行を進め、**数量が10以上の明細の件数**を数える。

- `For 〜 To 最終行` との書き分けを意識する（件数が読めないときは Do、読めるなら For）

### Q8. Select Case でランクを付ける ★★
社員名簿の J列に「給与ランク」を付ける。50万以上=A、40万台=B、30万台=C、それ未満=D。

- ヒント: `Select Case salary` / `Case Is >= 500000` / `Case 400000 To 499999`

### Q9. 二重ループで支店別集計 ★★★
支店5つを配列に入れ、支店ごとに売上明細を走査して合計を求め、「集計結果」の D・E 列に出力する。

- ヒント: `Array("東京本社", ...)` と `LBound / UBound`
- 気づいてほしいこと: **853行 × 5支店 = 4265回**もセルを読んでいる。Lv4 でこれを一気に速くします

# Lv3 実務操作 — 現場でそのまま使う技

### Q10. オートフィルタで抽出して別シートへ ★★★
売上明細を「東京本社」で絞り込み、可視セルだけを新しいシート `東京本社_抽出` にコピーする。
シートが既にあれば作り直すこと。

- ヒント: `.AutoFilter Field:=3, Criteria1:="東京本社"` → `.SpecialCells(xlCellTypeVisible).Copy`
- 落とし穴: 抽出0件で `SpecialCells` を呼ぶとエラーになる。事前に件数を確認する

### Q11. シートを安全に追加する ★★
`202609_月次` のように「今日の年月＋_月次」という名前のシートを作る。
**同名シートが既にあったら、上書きするか確認してから作り直す。**

- ヒント: 全シートを `For Each` で回して名前を照合する関数 `SheetExists` を自作する
- `Application.DisplayAlerts = False` で削除確認を抑制（**必ず True に戻す**）

### Q12. 並べ替え ★★
売上明細を「金額の降順」、同額なら「日付の昇順」で並べ替える。

- ヒント: `ws.Sort.SortFields.Clear` → `.Add` を2回 → `.SetRange` → `.Header = xlYes` → `.Apply`

### Q13. マスタから転記する（VLOOKUP相当）★★★
「在庫」シートの単価列を、商品コードをキーに「商品マスタ」から引き直して埋める。
**見つからなかった行はセルを薄い赤で塗る。**

- ヒント: `Application.VLookup(...)` を `Variant` で受けて `IsError` で判定する
  （`WorksheetFunction.VLookup` は見つからないと実行時エラーで止まります）

### Q14. 表の整形を自動化する ★★
アクティブシートの表に対して、罫線・見出し色・列幅自動調整・ウィンドウ枠固定・印刷設定（横向き/横1ページ/見出し行を各ページに印刷）をまとめて行う汎用マクロを書く。

- どのシートでも使えるように、最終行・最終列を自動判定すること

# Lv4 応用 — 速く、壊れないコードへ

### Q15. Dictionary で担当者別集計 ★★★★
`Scripting.Dictionary` を使って、担当者ごとの売上合計を1回のループで求め、「集計結果」の G・H 列に出力する。

- ヒント: `dic(key) = dic(key) + 金額` の1行が集計の核。存在チェックすら要りません
- **Mac の場合**: `Scripting.Dictionary` は使えません。`Collection` で代用します（解答例に Mac 版あり）

### Q16. 配列で高速化する ★★★★
同じ合計処理を「セルを1つずつ読む方式」と「`Range.Value` で配列に読み込む方式」の2通りで書き、`Timer` で速度を比較する。

- ヒント: `data = ws.Range("K2:K854").Value` で**2次元配列**になる（`data(行, 列)`、1始まり）
- 続けて、L列に税込金額を**一括で書き戻す**マクロも書く（`Range(...).Resize(n, 1).Value = 配列`）
- 体感してほしいこと: セルアクセスは遅い。**読むのも書くのも1回で済ませる**

### Q17. エラー処理の型を覚える ★★★
わざと存在しないシートを参照してエラーを起こし、次を満たすマクロを書く。

- `On Error GoTo ErrHandler` でエラーを捕まえ、エラー番号と内容を表示する
- 処理前に `ScreenUpdating / EnableEvents / Calculation` を止め、**エラーが起きても必ず元に戻す**
- ヒント: `ErrHandler:` → `Resume CleanUp` で後始末に合流させる

### Q18. ユーザー定義関数を作る ★★★
`Function` で、セルから `=税込(A1)` のように呼べる関数を作る。

1. `税込(金額, [税率])` — 税率は省略可能（既定10%）
2. `正規化(文字列)` — 全角→半角、全角スペース→半角、連続スペースを1つに、前後の空白除去
3. `年度(日付)` — 4月始まりの年度を返す（2025/3/31 → 2024）

- ヒント: `Optional rate As Double = 0.1` / `StrConv(s, vbNarrow)` / `Trim`

### Q19. 汚いデータを整える ★★★★
「要整形データ」シートを整形し、新しいシート `整形済みデータ` に出力する。

- [ ] 空行を飛ばす
- [ ] 顧客番号を大文字に統一（`c002` → `C002`）
- [ ] 会社名の前後・連続する空白を除去
- [ ] 全角数字を半角に（`１２００００` → `120000`）
- [ ] 電話番号の全角ハイフン `‐` を半角 `-` に
- [ ] 郵便番号を `123-4567` 形式に統一
- [ ] 金額を数値化（`1,450,000` `  92000  ` `３３０，０００` すべて数値に）
- [ ] 日付を日付型に（`2025年4月15日` `R7.5.2` `2025.6.1` すべて対応）
- [ ] 顧客番号が重複する行は1件だけ残す

- ヒント（重複判定）: `Collection` に `col.Add 値, キー` で追加し、`On Error Resume Next` でエラーが出たら重複、という定番テクニックがあります

# Lv5 総合課題 — 実務フロー1本を自動化する

### Q20. CSV取込 → 集計 → 帳票 → PDF ★★★★★

**Q20-1. 複数CSVの取り込み**
`データ/` フォルダ内の `*.csv` をすべて開き、1枚のシート `取込データ` に縦につなげる。

- 見出しは1ファイル目だけ残す
- ヒント: `Dir(パス & "*.csv")` で1件目、次からは引数なしの `Dir` で順に取得
- 途中でエラーになっても、開いた CSV を必ず閉じること

**Q20-2. クロス集計**
`取込データ` から「支店 × カテゴリ」の売上クロス集計表を作り、シート `クロス集計` に出力する。行末に合計列を付け、見出しに色と罫線を付ける。

- ヒント: 支店リストとカテゴリリストを一意に集め、`ReDim grid(1 To 支店数, 1 To カテゴリ数)` の2次元配列に足し込む

**Q20-3. 請求書の発行**
`InputBox` で伝票番号を受け取り、その伝票の明細を「請求書テンプレート」に書き出して PDF 保存する。

- 宛先・日付・請求番号・明細行・税込合計を埋める
- 該当なしなら警告して終了
- ヒント: `ExportAsFixedFormat Type:=xlTypePDF, fileName:=パス`

## 詰まったときのチェックリスト

| 症状 | 見るところ |
|---|---|
| `変数が定義されていません` | `Option Explicit` があるのに `Dim` を書き忘れている（これは良いエラー） |
| `インデックスが有効範囲にありません` | シート名のタイプミス、配列の添字 |
| `オブジェクトが必要です` | `Set` の書き忘れ（オブジェクト代入には `Set` が要る） |
| 意図しないシートが対象になる | `Range("A1")` と書くとアクティブシート基準。必ず `ws.Range("A1")` と書く |
| 遅い | セルを1つずつ触っていないか。配列に読んで、まとめて書き戻す |
| 途中で止まって画面が固まる | `ScreenUpdating = False` を戻せていない。`Ctrl + Break` で中断して `True` に戻す |
