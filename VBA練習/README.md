# Excel VBA 学習セット

```
VBA練習/
├── サンプルデータ.xlsx    ← まずこれを開く
├── 問題集.md              ← 全20問（Lv1〜Lv5）
├── 解答例.md              ← 解答コードまとめ（コピペ用）
├── 解答例/*.bas           ← 解答コード（VBEにインポート用）
└── データ/売上_*.csv      ← Lv5 で使う支店別CSV（5本）
```

## はじめかた

1. `サンプルデータ.xlsx` を開く
2. **「Excel マクロ有効ブック (.xlsm)」で別名保存**（同じフォルダに）
   → .xlsx のままではマクロを保存できません
3. `Alt + F11`（Mac は `Option + F11`）で VBE を開く
4. `挿入 > 標準モジュール`、先頭に `Option Explicit`
5. `問題集.md` の Q1 から順に

## 解答例の使い方

- **コピペ推奨**: `解答例.md` からコードをコピーして標準モジュールに貼る
- インポートする場合: VBE の `ファイル > ファイルのインポート` で `解答例/*.bas` を選択
  （UTF-8 で保存しているため、環境によっては日本語コメントが文字化けします。その場合はコピペしてください）

## 環境による違い

| | Windows | Mac |
|---|---|---|
| VBE を開く | `Alt + F11` | `Option + F11` |
| 開発タブ | ファイル > オプション > リボンのユーザー設定 | Excel > 環境設定 > リボンとツールバー |
| `Scripting.Dictionary` | 使える | **使えない** → `Collection` で代用（Q15 に Mac 版あり） |
| `FileSystemObject` | 使える | 使えない → `Dir` を使う |
| フォルダ走査 | そのまま動く | 初回に `GrantAccessToMultipleFiles` の許可が要ることあり |
| PDF 出力 | 動く | 動く |

Lv1〜Lv4 は Mac でもそのまま通ります。Lv5 の CSV 取込だけ、Mac ではフォルダアクセス許可でつまずくことがあります。

## 学習の順番（目安）

| レベル | テーマ | 目安 |
|---|---|---|
| Lv1 (Q1–4) | VBE・変数・セル操作 | 1〜2時間 |
| Lv2 (Q5–9) | If / For / Do / Select Case | 2〜3時間 |
| Lv3 (Q10–14) | フィルタ・シート操作・並べ替え・転記 | 3〜4時間 |
| Lv4 (Q15–19) | 高速化・エラー処理・UDF・データ整形 | 4〜6時間 |
| Lv5 (Q20) | 複数CSV→集計→帳票→PDF の総合課題 | 3〜5時間 |

Lv4 の Q16（配列で高速化）が一番の分かれ目です。ここを越えると、実務のマクロが「動くけど遅い」から「実用的」に変わります。
