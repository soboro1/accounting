デザインの基礎

デザインの4原則

センスではなく、4つのルールで見やすさは決まります。迷ったらこの4つに戻ります。

  • 近接:関係のあるものは近づけ、関係のないものは離す
  • 整列:端や中心を、見えない線でそろえる
  • 反復:同じ役割のものには、同じ色・形・サイズをくり返す
  • 対比:大事なものと、そうでないものの差をはっきりつける
同じ文章でも、4原則でここまで変わる

文字の基本

  • 本文の文字サイズは 16px が基準
  • 日本語の本文の行間(line-height)は 1.5〜1.8 が読みやすい
  • フォントの種類は2つまで、太さとサイズの差でメリハリをつける
行間の計算:文字サイズ × 行間の倍率
(例)16px × 1.75 = 28px  → Figmaの行間は「28」または「175%」

コントラスト比(読めるかどうかの基準)

文字色と背景色の明るさの差を「コントラスト比」といいます。アクセシビリティの基準(WCAG)では、次の値が目安です。

  • ふつうの本文:4.5:1 以上(AA)
  • 大きな文字(24px以上、または太字で約19px以上):3:1 以上(AA)

CHAPTER 2

Figmaの基本

Figmaとは

Figmaは、ブラウザで動くデザインツールです。インストール不要で、複数人が同じファイルを同時に編集でき、無料プランから始められます。Webデザインの現場で、いま最も広く使われています。

ファイルの構造

ファイル› ページ› フレーム› レイヤー(図形・テキスト・画像)
  • フレーム:画面1枚分の「台紙」。中にさらにフレームを入れて、ヘッダーやカードなどのパーツも作る
  • レイヤー:左のパネルに並ぶ、1つ1つの部品。上にあるものほど手前に表示される

フレームとグループの違い

  • フレーム:自分のサイズ・塗り・角丸を持てる箱。オートレイアウトや制約を設定できる。HTMLの <div> にあたる
  • グループ:複数のレイヤーをまとめて動かすためだけのもの。大きさは中身で決まる
Webデザインでは、基本的にフレームを使います。あとでHTML/CSSにするとき、フレームがそのまま1つの要素になるからです。

まず覚えるショートカット

MacのCmdは、WindowsではCtrlです(OptionはAlt)。

  • F フレーム / R 長方形 / O 楕円 / T テキスト / V 移動(選択)
  • Shift+A オートレイアウトを追加
  • Cmd+D 複製 / Cmd+G グループ化 / Cmd+R レイヤー名の変更
  • Option+Cmd+G 選択範囲をフレーム化
  • Option+Cmd+K コンポーネントを作成
  • Shift+1 全体を表示 / Shift+2 選択したものを拡大表示
  • Option を押しながらマウスを動かす:ほかの要素との距離(余白)を表示

レイヤーには名前をつける

「Frame 127」のままにせず、header card button のように役割で名前をつけます。この名前が、そのままHTMLのクラス名の候補になります。

CHAPTER 3

オートレイアウト

中身に合わせて伸び縮みする箱

フレームを選んで Shift+A を押すと、オートレイアウトになります。中の要素が自動で並び、文字数が変わっても余白が保たれます。Figmaで一番大事な機能です。

決めるのは4つだけ

  • 方向:横に並べるか、縦に並べるか(折り返しもできる)
  • アイテムの間隔:要素と要素のあいだの距離
  • パディング:フレームの内側の端と、中身のあいだの余白
  • 揃え:左・中央・右、上・中央・下のどこに寄せるか

サイズの3つの決め方

  • 固定(Fixed):数値で決めた大きさのまま
  • コンテンツを内包(Hug):中身にぴったり合わせて大きさが決まる
  • コンテナに合わせて拡大(Fill):親フレームの残りのスペースいっぱいに広がる
内包(Hug)のときの幅の計算:
幅 = 中身の幅の合計 + 間隔 ×(個数 − 1)+ 左右のパディング

(例)幅80の要素が3つ、間隔16、左右のパディング24
80 × 3 + 16 × 2 + 24 × 2 = 320
拡大(Fill)のときの幅の計算:
1つの幅 =(親の幅 − 左右のパディング − 間隔 ×(個数 − 1))÷ 個数

(例)親の幅416、左右のパディング24、間隔16、子が3つ
(416 − 24 × 2 − 16 × 2)÷ 3 = 112

しま模様の部分がパディングです。間隔を「自動」にすると、要素が両端にそろい、あいだが均等に広がります(CSSの space-between)。


    
入れ子にして画面を組む

CHAPTER 4

    
コンポーネントとスタイル


    
コンポーネント = 使い回せる部品

    
ボタンやカードなど、何度も使うパーツはコンポーネントにします(Option+Cmd+K)。

    
    
      
  • メインコンポーネント:元になる部品。ここを直すと、すべてのコピーに反映される
    • 
      
  • インスタンス:メインから作ったコピー。文字や色だけを個別に変えられる(上書き)
    • 
    

    

      メインコンポーネントを修正→
      すべてのインスタンスに反映
    

    
インスタンスで上書きした部分(たとえばボタンの文字)は、メインを変更しても保たれます。メインとのつながりを切りたいときは「インスタンスの切り離し」をします。


    
バリアント = 状態やサイズ違いをまとめる

    
ボタンの「通常・ホバー・無効」や「大・中・小」のような違いは、バリアントとして1つのコンポーネントにまとめます。インスタンス側では、プロパティを切り替えるだけで見た目が変わります。


    
スタイルとバリアブル

    
    
      
  • カラースタイル:色に名前をつけて登録(例:primary)
    • 
      
  • テキストスタイル:フォント・サイズ・太さ・行間・字間のセット(文字色は含まない)
    • 
      
  • エフェクトスタイル:シャドウやぼかし
    • 
      
  • バリアブル:色や数値に名前をつけた「変数」。ライト/ダークなどのモードで値を切り替えられる
    • 
    

    
色やサイズを直接入力せず、スタイルやバリアブルから選ぶようにすると、あとから「メインカラーを変えたい」となっても1か所の修正で済みます。CSSでいうCSS変数(カスタムプロパティ)と同じ考え方です。

    
Figmaのバリアブル          CSSの変数
color/primary = #1F4FD8  →  --color-primary: #1f4fd8;
space/md      = 16       →  --space-md: 16px;


    
  


  
  

    
CHAPTER 5

    
制約とレスポンシブ


    
制約 = 親の大きさが変わったときの動き方

    
オートレイアウトではないフレームの中では、制約で「親フレームのどこにくっつくか」を決めます。

    
    
      
  • 左:左端からの距離を保つ(初期設定)
    • 
      
  • 右:右端からの距離を保つ
    • 
      
  • 左右:左右両方の距離を保つ → 幅が伸び縮みする
    • 
      
  • 中央:中心からのずれを保つ
    • 
      
  • 拡大縮小:親に対する割合を保つ
    • 
    

    

      
親フレームを広げたとき(上:元の幅 / 下:広げたあと)

(例)幅400の親 → 600に広げる。子は 左から40・幅120(右から240)

制約「右」  :右から240を保つ → 新しいX = 600 − 240 − 120 = 240
制約「左右」:左40・右240を保つ → 新しい幅 = 600 − 40 − 240 = 320
制約「中央」:広がった分の半分だけ動く → 新しいX = 40 + 200 ÷ 2 = 140
制約「拡大縮小」:1.5倍になる → 新しい幅 = 120 × 1.5 = 180


    
レスポンシブデザイン

    
スマホ・タブレット・パソコンなど、画面の幅に合わせてレイアウトを切り替えることをレスポンシブデザインといいます。切り替える境目の幅がブレイクポイントです。

    
    
      
  • スマホ:〜767px(デザインは幅375や390で作ることが多い)
    • 
      
  • タブレット:768px〜
    • 
      
  • パソコン:1024px〜(デザインは幅1280や1440で作ることが多い)
    • 
    

    
小さい画面から先に作る進め方をモバイルファーストといいます。スマホで入り切る内容に絞ってから、広い画面で横に並べ直すと破綻しにくくなります。


    
カラムグリッド

    
フレームに「レイアウトグリッド」を設定すると、縦のガイド(カラム)が表示されます。パソコンは12カラム、スマホは4カラムがよく使われます。12は2・3・4・6で割り切れるので、2列にも3列にも4列にも分けやすいからです。

    
1カラムの幅 =(全体の幅 − 左右のマージン × 2 − ガター ×(カラム数 − 1))÷ カラム数

(例)全体1200、マージン0、ガター24、12カラム
(1200 − 24 × 11)÷ 12 = 78


    
広がりすぎを止める

    
オートレイアウトのフレームには、最小幅・最大幅を設定できます。本文が横に広がりすぎると読みにくいので、「最大幅 1200」のように上限を決めます(CSSの max-width)。


    
  


  
  

    
CHAPTER 6

    
FigmaからHTML/CSSへ


    
フレーム = 要素、オートレイアウト = Flexbox

    
Figmaの設定は、ほぼそのままCSSに置き換えられます。

    

      
フレーム→<div> などの要素

      
オートレイアウト→display: flex;

      
方向(横 / 縦)→flex-direction: row; / column;

      
アイテムの間隔→gap

      
間隔「自動」→justify-content: space-between;

      
パディング→padding

      
並ぶ方向の揃え→justify-content

      
垂直方向の揃え→align-items

      
折り返し→flex-wrap: wrap;

      
内包(Hug)→幅を指定しない(width: fit-content;)

      
拡大(Fill)→flex: 1;(並ぶ方向) / align-self: stretch;(垂直方向)

      
固定(Fixed)→width: 320px; のように数値で指定

    


    
見た目のプロパティ

    

      
塗り(フレーム・図形)→background-color

      
塗り(テキスト)→color

      
線(ストローク)→border

      
角の半径→border-radius

      
ドロップシャドウ→box-shadow

      
不透明度→opacity

      
行間 / 字間→line-height / letter-spacing

    


    
カードを実装してみる

    
Figmaの設定
card  :オートレイアウト(縦)/ 間隔12 / パディング24 / 角の半径12 / 塗り #FFFFFF / 幅320(固定)
title :20px・太字     text:14px・行間1.75
button:オートレイアウト(横)/ パディング 上下12・左右24 / 角の半径8 / 塗り #1F4FD8

    
<article class="card">
  <h2 class="card-title">Figma入門講座</h2>
  <p class="card-text">初心者向けに基本操作を学びます。</p>
  <a class="button" href="#">申し込む</a>
</article>

    
.card {
  display: flex;
  flex-direction: column;   /* 方向:縦 */
  gap: 12px;                /* アイテムの間隔 */
  padding: 24px;            /* パディング */
  width: 320px;             /* 固定 */
  border-radius: 12px;      /* 角の半径 */
  background-color: #ffffff;
}
.card-title { font-size: 1.25rem; font-weight: 700; }
.card-text  { font-size: 0.875rem; line-height: 1.75; }
.button {
  display: flex;
  justify-content: center;
  align-self: flex-start;   /* 内包(Hug):文字の長さに合わせる */
  padding: 12px 24px;       /* 上下12・左右24 */
  border-radius: 8px;
  background-color: #1f4fd8;
  color: #ffffff;           /* テキストの塗り */
}


    
paddingの書き方

    
padding: 24px;                 /* 上下左右すべて24 */
padding: 12px 24px;            /* 上下12・左右24 */
padding: 8px 16px 24px 32px;   /* 上8・右16・下24・左32(時計回り) */


    
pxとrem

    
Figmaの数値はpxですが、CSSの文字サイズは rem で書くのが一般的です。remは「ブラウザの基準の文字サイズ(ふつう16px)の何倍か」を表し、利用者が文字を大きくする設定をしたときに一緒に拡大されます。

    
rem = px ÷ 16
(例)24px ÷ 16 = 1.5rem   14px ÷ 16 = 0.875rem


    
レスポンシブはメディアクエリで

    
/* モバイルファースト:まずスマホ用(縦並び) */
.cards { display: flex; flex-direction: column; gap: 16px; }

/* 768px以上になったら横並びに */
@media (min-width: 768px) {
  .cards { flex-direction: row; gap: 24px; }
}


    
開発モードと書き出し

    
    
      
  • 開発モード(Shift+D):要素を選ぶと、サイズ・余白・色・CSSのコードを確認できる(有料プラン向けの機能。無料でも右パネルで数値は確認できる)
    • 
      
  • 書き出し:右パネルの「エクスポート」から。ロゴやアイコンはSVG、写真はJPG、透過が必要な画像はPNG
    • 
      
  • PNG・JPGは 2x(2倍)で書き出すと、高解像度の画面でもぼやけない(表示幅300pxなら600pxの画像になる)
    • 
    

    
出てきたCSSをそのまま貼るのではなく、「どのフレームがどのHTML要素になるか」を自分で決めるのがコツです。見出しは <h1>〜、ナビは <nav>、ボタンは <button> か <a> と、意味に合ったタグを選びます。
