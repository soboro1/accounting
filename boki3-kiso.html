CHAPTER 1

簿記の目的と5要素

簿記とは

簿記は、会社のお金やモノの動き(取引)を記録・計算・整理して、最終的に財務諸表という成績表を作るための技術です。

  • 貸借対照表(B/S):決算日時点で、会社がどれだけ財産と借金を持っているか(財政状態)を表す
  • 損益計算書(P/L):1年間でどれだけ稼ぎ、どれだけ使って、いくら儲かったか(経営成績)を表す

会社の1年間の区切りを会計期間といい、始まりの日を期首、終わりの日を期末(決算日)、その間を期中と呼びます。

5つの要素

簿記では、すべての勘定科目(記録するときの項目名)が次の5つのどれかに分かれます。

  • 資産:会社が持っている財産や、将来お金を受け取れる権利。
    例)現金、普通預金、売掛金、貸付金、建物、備品、土地
  • 負債:将来お金を支払わなければならない義務。
    例)買掛金、借入金、未払金、預り金
  • 純資産:資産から負債を引いた残り。株主が出したお金や、これまでの儲けの蓄え。
    例)資本金、繰越利益剰余金
  • 収益:純資産を増やす原因になる「稼ぎ」。
    例)売上、受取利息、受取手数料、受取家賃
  • 費用:収益を得るために使ったもの。
    例)仕入、給料、支払家賃、水道光熱費、通信費、支払利息

財務諸表の形

資産・負債・純資産は貸借対照表に、収益・費用は損益計算書に載ります。

貸借対照表(左)
資産
貸借対照表(右)
負債
純資産
資産 = 負債 + 純資産      (貸借対照表等式)
資産 − 負債 = 純資産      (資本等式)
損益計算書(左)
費用
当期純利益
損益計算書(右)
収益
収益 − 費用 = 当期純利益   (マイナスなら当期純損失)
期首と期末の純資産を比べても利益がわかります。株主からの追加出資などがなければ、
期末純資産 − 期首純資産 = 当期純利益
CHAPTER 2

仕訳のルール

簿記上の取引

簿記で記録するのは、5要素のどれかが増えたり減ったりしたことだけです。日常の言葉の「取引」とは少しずれます。

  • 取引になる:商品を売った、お金を借りた、給料を払った、火災や盗難で財産がなくなった
  • 取引にならない:契約を結んだ、商品を注文した、人を雇う約束をした(まだ何も増減していない)

仕訳とは

1つの取引を左側(借方・かりかた)と右側(貸方・かしかた)の2つに分けて記録することを仕訳といいます。「借」「貸」の字に意味はなく、ただの左右の名前だと思ってOKです。

覚え方:「かりかた」の「り」は左にはらう → 左。「かしかた」の「し」は右にはらう → 右。

左右を決めるルール(ホームポジション)

5要素にはそれぞれ定位置があります。貸借対照表・損益計算書で載っている側と同じです。

借方(左)が定位置
資産
費用
貸方(右)が定位置
負債
純資産
収益
  • 増えたら定位置の側に書く(資産が増えたら借方、負債が増えたら貸方)
  • 減ったら反対側に書く(資産が減ったら貸方、負債が減ったら借方)
  • 収益・費用は、ふつう増える(発生する)ときだけ出てきます

仕訳の手順

  • ① 何が動いたか、勘定科目を2つ(以上)見つける
  • ② それぞれ5要素のどれか、増えたか減ったかを考える
  • ③ ルールに従って左右に置き、金額を書く

仕訳の例

株式を発行し、株主から現金1,000,000円の出資を受けた。

(借)現金   1,000,000   (貸)資本金   1,000,000
  資産の増加 → 借方      純資産の増加 → 貸方

銀行から現金300,000円を借り入れた。

(借)現金     300,000   (貸)借入金     300,000
  資産の増加 → 借方      負債の増加 → 貸方

事務用のパソコン(備品)を150,000円で買い、現金で支払った。

(借)備品     150,000   (貸)現金       150,000
  資産の増加 → 借方      資産の減少 → 貸方

商品80,000円を仕入れ、代金は掛け(後払い)とした。

(借)仕入      80,000   (貸)買掛金      80,000
  費用の発生 → 借方      負債の増加 → 貸方

商品を120,000円で売り上げ、代金は現金で受け取った。

(借)現金     120,000   (貸)売上       120,000
  資産の増加 → 借方      収益の発生 → 貸方

給料50,000円を現金で支払った。

(借)給料      50,000   (貸)現金        50,000
  費用の発生 → 借方      資産の減少 → 貸方
どの仕訳も借方の合計金額 = 貸方の合計金額になります。これを貸借平均の原理といい、後で学ぶ試算表の土台になります。
CHAPTER 3

転記と総勘定元帳

仕訳帳と総勘定元帳

  • 仕訳帳:仕訳を日付順に記録する帳簿
  • 総勘定元帳:勘定科目ごとにページ(口座)を分けて、増減を集計する帳簿

仕訳帳の内容を総勘定元帳の各勘定に書き写すことを転記といいます。仕訳帳と総勘定元帳は、どの会社でも必ず作る主要簿です。

転記のルール

  • 仕訳の借方の科目 → その勘定の借方に書く
  • 仕訳の貸方の科目 → その勘定の貸方に書く
  • 書くのは日付・相手科目・金額(自分の科目名ではなく、仕訳の反対側の科目を書く)

例)4月1日 株式を発行し、現金500,000円の出資を受けた。

4/1 (借)現金 500,000   (貸)資本金 500,000

この仕訳を試験で使う簡単な形(T字勘定)に転記すると、次のようになります。

現金
4/1 資本金500,000
資本金
4/1 現金500,000

現金勘定の借方に「資本金」と書くのは、「資本金が理由で現金が増えた」という意味です。

相手科目が2つ以上あるとき

相手科目が複数ある場合は、相手科目欄に諸口(しょくち)と書きます。

4/5 (借)備品 200,000   (貸)現金   120,000
                           未払金  80,000

備品勘定の借方には「4/5 諸口 200,000」、現金勘定の貸方には「4/5 備品 120,000」、未払金勘定の貸方には「4/5 備品 80,000」と書きます。

勘定の残高

勘定の借方合計と貸方合計の差額を残高といいます。大きい方の側に残高が残ります。

現金
4/1 資本金500,000
4/20 売上90,000
4/5 備品120,000
4/25 給料60,000
借方合計 590,000 − 貸方合計 180,000 = 借方残高 410,000(手元の現金)
資産の勘定はふつう借方残高、負債・純資産の勘定は貸方残高になります。定位置のルールと同じです。
CHAPTER 4

試算表

試算表とは

総勘定元帳のすべての勘定の金額を1枚に集めた表です。仕訳はどれも借方と貸方が同じ金額なので、正しく転記されていれば試算表の借方合計と貸方合計は必ず一致します。これを使って転記ミスを確かめます。

3つの種類

  • 合計試算表:各勘定の借方合計と貸方合計をそのまま集める
  • 残高試算表:各勘定の残高だけを集める(試験でいちばんよく出る)
  • 合計残高試算表:合計と残高の両方を並べる

残高試算表の作り方

第3章の例に、次の勘定があったとします。

現金     借方合計 590,000 / 貸方合計 180,000 → 借方残高 410,000
備品     借方合計 200,000                     → 借方残高 200,000
給料     借方合計  60,000                     → 借方残高  60,000
未払金                     貸方合計  80,000  → 貸方残高  80,000
売上                       貸方合計  90,000  → 貸方残高  90,000
資本金                     貸方合計 500,000  → 貸方残高 500,000

残高を借方・貸方に分けて並べると、残高試算表になります。

  借方           勘定科目          貸方
  410,000        現金
  200,000        備品
                 未払金           80,000
                 資本金          500,000
                 売上             90,000
   60,000        給料
─────────────────────────────────────
  670,000        合計            670,000   ← 一致!
並べる順番は、資産 → 負債 → 純資産 → 収益 → 費用 が基本です。借方に来るのは資産と費用、貸方に来るのは負債・純資産・収益です。

試算表で見つけられない誤り

貸借の一致だけを確かめるので、借方と貸方に同じだけ影響する誤りは見つけられません。

  • 取引をまるごと仕訳し忘れた・転記し忘れた
  • 同じ仕訳を2回転記した
  • 勘定科目を間違えた(たとえば現金を普通預金にした)
  • 借方と貸方を逆にして転記した

反対に、「借方だけ転記して貸方を忘れた」「金額を片側だけ書き間違えた」といった誤りは、合計が一致しなくなるので見つけられます。
