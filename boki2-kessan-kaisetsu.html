費用と収益を当期の分だけにそろえ、将来の支払いに備え、最後に税金を計算します。

経過勘定

  • 前払費用:保険料 6,000 のうち翌期の分が 2,000 → 費用から除く

  • 前受収益:受取家賃 3,600 のうち翌期の分が 600 → 収益から除く
  • 未収収益:当期の収益で未収の分があれば、収益に加える

買掛金のうち 100千ドルは、1ドル108円で記帳しています。決算日の為替相場は1ドル110円です。決算日のレートに直すと、買掛金は 100 × (110 − 108)＝ 200 増えます。

4-4頻出度 ★★

精算表(8桁)

同じ内容を1枚に集めたのが精算表です。試算表に修正を加え、収益と費用は損益計算書の欄へ、それ以外は貸借対照表の欄へ移します。

4-5試験の手順

試験で解く順番

  1. 資料を読み、下書きに仕訳を書く試算表の金額に、その場で増減を書き足すと速くなります。
  2. 売上原価と商品を先に確定する売上原価を間違えると、後ろの利益がすべてずれます。
  3. 税金以外の決算整理をすべて終える貸倒引当金、減価償却、有価証券、経過勘定、引当金、外貨換算です。
  4. 損益計算書を上から埋める段階利益を順に出して、税引前当期純利益まで進みます。
  5. 法人税等を計算し、貸借対照表を埋める繰越利益剰余金は、試算表の金額に当期純利益を足します。

    資産の決算整理：まずここから

    1. 減耗は原価で、評価損は実地数量で計算する
    2. 貸倒引当金は差額を繰り入れる
    3. 定率法は期首の帳簿価額に掛ける
    4. 有価証券は保有目的で処理を分ける

    負債と損益の決算整理：まずここから

    1. 経過勘定で費用と収益を当期分にそろえる
    2. 引当金は当期の負担額を費用にする
    3. 外貨建の売掛金と買掛金を決算日のレートに直す
    4. 法人税等は最後に計算する

    財務諸表：まずここから

    1. 5つの段階利益の順番を覚える
    2. 科目の区分を覚える(特に営業外と投資その他)
    3. 繰越利益剰余金に当期純利益を足す
    4. 貸借対照表の左右の合計で検算する

    つなげて覚えるコツ：決算整理の仕訳は、費用や収益と、資産や負債がセットです。片方が損益計算書へ、もう片方が貸借対照表へ行きます。迷ったら、この金額はどちらの表に行くのかを考えます。

    問題アプリで練習する数字を変えて、仕訳と財務諸表の集計まで確認できます
