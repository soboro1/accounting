CHAPTER 1

仕訳帳・総勘定元帳と補助簿

主要簿と補助簿

  • 主要簿:どの会社も必ず作る帳簿。仕訳帳と総勘定元帳の2つ(①で学習)
  • 補助簿:主要簿を補うために、特定の取引や勘定をくわしく記録する帳簿

補助簿は、さらに2種類に分かれます。

  • 補助記入帳(取引の明細を記録):現金出納帳、当座預金出納帳、小口現金出納帳、仕入帳、売上帳、受取手形記入帳、支払手形記入帳
  • 補助元帳(勘定の明細を相手や商品ごとに記録):売掛金元帳、買掛金元帳、商品有高帳、固定資産台帳

どの補助簿に記入するか

試験では「この取引を記入する補助簿をすべて選べ」という問題がよく出ます。仕訳をしてから、出てきた勘定科目ごとに補助簿を考えるのがコツです。

  • 現金 → 現金出納帳 / 当座預金 → 当座預金出納帳 / 小口現金 → 小口現金出納帳
  • 仕入 → 仕入帳 と 商品有高帳 / 売上 → 売上帳 と 商品有高帳
  • 売掛金 → 売掛金元帳 / 買掛金 → 買掛金元帳
  • 受取手形 → 受取手形記入帳 / 支払手形 → 支払手形記入帳
  • 備品・建物など → 固定資産台帳
例)商品50,000円を掛けで売り上げた
仕訳:(借)売掛金 50,000 (貸)売上 50,000
→ 売掛金元帳、売上帳、商品有高帳(商品が出ていく)
仕入や売上のときは、商品の数が動くので商品有高帳も忘れずに。返品のときも商品が動くので記入します。

総勘定元帳から取引を読み取る

元帳の記入は「日付・相手科目・金額」なので、逆に元帳から仕訳を復元することもできます。

現金勘定の借方に「10/5 売掛金 30,000」
→ 現金が借方(増加)、相手は売掛金
→ (借)現金 30,000 (貸)売掛金 30,000
CHAPTER 2

現金出納帳・当座預金出納帳

現金出納帳

現金の収入・支出を、日付順に明細つきで記録する補助簿です。残高が常にわかります。

10/1  前月繰越                収入 50,000           残高 50,000
10/5  A商店から売掛金回収     収入 30,000           残高 80,000
10/12 事務用品の購入                      支出 8,000  残高 72,000
10/31 次月繰越                                        72,000
  • 月末の残高は「次月繰越」として締め切り、翌月は「前月繰越」から始める
  • 残高 = 前月繰越 + 収入の合計 − 支出の合計

当座預金出納帳

当座預金の預け入れ・引き出し(小切手の振り出し)を記録します。当座借越契約がある場合、残高がマイナスになることがあり、「借/貸」欄で区別します。

  • 借:当座預金の残高がある(借方残高)
  • 貸:残高を超えて引き出している=当座借越(貸方残高)
10/1  前月繰越        預入 100,000               借  100,000
10/8  小切手振出(仕入)          引出 150,000     貸   50,000 ← 借越
10/20 売掛金回収      預入  80,000               借   30,000
CHAPTER 3

小口現金出納帳

小口係がつける帳簿

②で学んだ小口現金(定額資金前渡法)の受け入れと支払いを、小口係が記録する補助簿です。支払いは内訳欄で費用の種類ごとに分けて書きます。

受入 30,000  10/1 前週繰越
             10/2 タクシー代    支払 3,000(内訳:旅費交通費)
             10/3 切手代        支払 1,200(内訳:通信費)
             10/4 文房具代      支払 2,500(内訳:消耗品費)
             10/5 電車代        支払   800(内訳:旅費交通費)
                  合計          支払 7,500
受入  7,500  10/5 本日補給
             10/5 次週繰越            30,000
  • 内訳ごとの合計が、会計係の仕訳の費用の金額になる(旅費交通費3,800、通信費1,200、消耗品費2,500)
  • 補給額 = 支払の合計(使った分だけ補給して、元の30,000円に戻る)

報告と同時に補給したときの仕訳

(借)旅費交通費  3,800   (貸)当座預金  7,500
    通信費      1,200
    消耗品費    2,500
CHAPTER 4

仕入帳・売上帳

仕入・売上の明細を記録する

仕入帳は仕入の、売上帳は売上の明細(相手先・品名・数量・単価・代金の支払方法)を記録する補助簿です。

仕入帳
10/3  A商店  掛  商品X 100個 @300          30,000
             引取運賃(現金払い)             1,000   ← 仕入に含める
10/9  B商店  掛  商品Y  50個 @400          20,000
10/10 B商店  掛返品 商品Y 5個 @400          2,000   ← 返品(赤字で記入)
10/31              総仕入高                51,000
       〃          仕入戻し高               2,000
       〃          純仕入高                49,000
  • 総仕入高 = 返品を引く前の仕入の合計(当社負担の引取運賃も含む)
  • 純仕入高 = 総仕入高 − 仕入戻し高
  • 売上帳も同じ形で、純売上高 = 総売上高 − 売上戻り高。売上のときの発送費は売上帳には含めない(発送費勘定)
返品は赤字(問題文では「赤記」)で記入するのが決まりです。
CHAPTER 5

売掛金元帳・買掛金元帳

取引先ごとの明細

総勘定元帳の売掛金勘定は、全部の得意先の合計しかわかりません。そこで、得意先ごとに売掛金の増減を記録するのが売掛金元帳(得意先元帳)です。仕入先ごとの買掛金元帳(仕入先元帳)も同じです。

売掛金元帳  A商店
10/1  前月繰越        借方 40,000           残高 40,000
10/8  売上            借方 60,000           残高 100,000
10/12 返品                        貸方 5,000 残高 95,000
10/25 回収(普通預金)            貸方 50,000 残高 45,000
  • 残高 = 前月繰越 + 売上 − 返品 − 回収
  • 全部の得意先の残高を合計すると、総勘定元帳の売掛金の残高と一致する
  • 買掛金元帳は貸方が増加(仕入)、借方が減少(返品・支払い)
CHAPTER 6

商品有高帳(先入先出法・移動平均法)

商品の在庫を「原価」で記録する

商品の種類ごとに、受け入れ(仕入)・払い出し(売上)・残高を数量・単価・金額で記録する補助簿です。売価ではなく仕入原価で記入するのがポイントです。

同じ商品でも仕入れた時期によって単価が違うため、払い出しの単価の決め方が2つあります。

先入先出法

先に仕入れたものから先に払い出したと考える方法です。

10/1  前月繰越  100個 @500
10/5  仕入      200個 @530
10/12 売上      250個
  → 先に古い100個 @500 = 50,000
     次に新しい150個 @530 = 79,500
     払出(売上原価)= 129,500
  残り 50個 @530 = 26,500

移動平均法

仕入れるたびに平均単価を計算し直し、その単価で払い出す方法です。

10/1  前月繰越  100個 @500 = 50,000
10/5  仕入      200個 @530 = 106,000
  → 平均単価 =(50,000 + 106,000)÷(100 + 200)= @520
10/12 売上      250個 @520 = 130,000(売上原価)
  残り 50個 @520 = 26,000

売上原価と売上総利益

売上原価   = 払出欄の金額の合計
売上総利益 = 売上高(売価 × 販売数量)− 売上原価
払い出しの単価は、売った値段(売価)ではなく原価です。問題文に売価が出てきても、商品有高帳には書きません。
CHAPTER 7

受取手形記入帳・支払手形記入帳

手形の明細を記録する

④で学んだ約束手形の明細(手形番号・振出人・満期日など)を記録する補助簿です。最後のてん末欄には、その手形がどうなったか(入金された、支払ったなど)を書きます。

受取手形記入帳
日付  摘要   手形番号  支払人  振出日  満期日  金額     てん末
10/5  売掛金  No.12    A商店   10/5   11/30  80,000   11/30 入金

記入帳から仕訳を読み取る

  • 摘要欄は、手形を受け取った(振り出した)ときの相手科目
  • てん末欄は、その後の決済などを表す
10/5 (借)受取手形 80,000 (貸)売掛金   80,000   ← 摘要が「売掛金」
11/30(借)当座預金 80,000 (貸)受取手形 80,000   ← てん末「入金」

支払手形記入帳も同じ読み方です。摘要が「買掛金」なら (借)買掛金 (貸)支払手形、てん末が「支払」なら (借)支払手形 (貸)当座預金 です。
