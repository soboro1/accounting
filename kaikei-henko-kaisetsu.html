PART 1

4つの区分と処理

基になるのは、企業会計基準第24号「会計方針の開示、会計上の変更及び誤謬の訂正に関する会計基準」です。まず、変更や訂正が4つのうちどれに当たるかを決めます。区分が決まれば、処理も決まります。

1-1頻出度 ★★★

さかのぼるか、さかのぼらないか

ひっかけ注意
  • ×過去の誤謬の訂正は、会計上の変更の1つである会計上の変更は、方針・表示・見積りの3つです。誤謬の訂正は別枠です。
  • ×会計上の見積りの変更は、遡及して過去の財務諸表を修正する遡及しません。変更した期と将来に反映します。
1-2頻出度 ★★

4つの用語の定義

会計方針

財務諸表の作成にあたって採用した会計処理の原則および手続。

表示方法

財務諸表の作成にあたって採用した表示の方法（科目、区分、配列など）。

会計上の見積り

資産・負債や収益・費用などの額に不確実性がある場合に、財務諸表作成時に入手可能な情報にもとづいて、その合理的な金額を算出すること。

誤謬

意図的かどうかにかかわらず、財務諸表作成時に入手可能な情報を使わなかったこと、または誤って使ったことによる誤り。

1-3頻出度 ★★

変更できる場合と、方針の変更に当たらないもの

改正会計基準等の改正により、会計方針を変更する。
自発正当な理由にもとづいて、自発的に会計方針を変更する。利益を調整する目的での変更は認められません。
重要取引などの重要性が増したため、本来の会計処理に変えること → 会計方針の変更に当たらない。例：重要性が乏しいとして費用処理していたものを、資産計上に変える。
新規新たに生じた取引に、新しい会計方針を採用すること → 会計方針の変更に当たらない。
ひっかけ注意
  • ×重要性が増したことにより、本来の会計処理に変更することは、会計方針の変更に当たる会計方針の変更に当たらないので、遡及適用もしません。
PART 2

会計方針の変更と遡及適用

会計方針を変えたら、新しい方法を最初から使っていたかのように、過去にさかのぼって処理します（遡及適用）。前期と当期を同じ方法で比べられるようにするためです。

2-1頻出度 ★★★

遡及適用と累積的影響額

原則新しい会計方針を、過去のすべての期間に遡及適用する。
経過会計基準等の改正に経過的な取扱いが定められていれば、それに従う。
不能1表示する期間のどこかで累積的影響額を出せないとき：遡及適用できる最も古い期間の期首から適用する。
不能2当期の期首時点でも過去の累積的影響額を出せないとき：実務上可能な最も古い日から、将来にわたって適用する。
ひっかけ注意
  • ×遡及適用による累積的影響額は、当期の特別損益（前期損益修正）に計上する表示する最も古い期間の期首の純資産などに反映します。損益計算書には出しません。
  • ×遡及適用しても、前期の財務諸表（比較情報）は修正しない比較情報も新しい方法で作り直します。期間比較ができるようにするのが目的です。

PART 3

見積りの変更と誤謬の訂正

見積りの変更は過去を直しません。誤謬の訂正は過去を直します。違いは「過去の見積りが、そのときの最善だったかどうか」です。

3-1頻出度 ★★★

会計上の見積りの変更

当期影響が変更した期だけに及ぶ場合：その期に処理する。例：貸倒見積高の見直し。
将来将来の期にも及ぶ場合：その期と将来の期に処理する。例：耐用年数の見直し。
耐用年数の変更（取得原価10,000、残存価額ゼロ、10年の定額法で4年償却した後、当期首に残り3年に変更）
(借)減価償却費2,000(貸)減価償却累計額2,000
期首の帳簿価額 10,000 − 4,000 ＝ 6,000 を残り3年で配分します。過去の償却不足をまとめて計上する臨時償却は行いません。
3-2頻出度 ★★★

減価償却方法の変更は「見積りの変更と同じ扱い」

性質は会計方針の変更減価償却方法は会計処理の手続

  1. 変更には正当な理由が必要
  2. 変更の内容や理由を注記する

処理は見積りの変更と同じ区別することが難しいため

  1. 遡及適用しない過去の償却額は直さない
  2. 変更した期の期首の帳簿価額を、残りの耐用年数で新しい方法により償却する
ひっかけ注意
  • ×減価償却方法の変更は会計方針の変更なので、遡及適用する見積りの変更と区別するのが難しいので、見積りの変更と同じく遡及適用しません。
  • ×減価償却方法は見積りの変更と同じ扱いなので、正当な理由がなくても変更できる性質は会計方針の変更なので、正当な理由が必要です。
3-3頻出度 ★★

誤謬の訂正と、見積りの変更との区別

見積りの変更過去の見積りは、そのときの最善だった

  1. 新しい情報が入ったので見直した
  2. 差額は当期の損益で処理する例：引当金の取崩額と見積額の差

誤謬入手できた情報を見落とした、誤って使った

  1. 過去の財務諸表が誤っていた
  2. 修正再表示する前期損益修正として当期の損益にはしない
前期の減価償却費1,000の計上漏れを、当期に発見した
(借)繰越利益剰余金1,000(貸)減価償却累計額1,000
前期の財務諸表（比較情報）も、正しい金額で表示し直します。誤謬に重要性が乏しければ、修正再表示をせず当期の損益で処理することもできます。
ひっかけ注意
  • ×過去の誤謬の訂正は、前期損益修正損益として当期の損益計算書に計上するのが原則である原則は修正再表示です。
  • ×過去の見積りが最善のものだった場合でも、実績と違えば誤謬である最善の見積りなら、見積りの変更として当期で処理します。
計算問題 2　どの区分に当たるか

次の変更や訂正は、4つの区分のどれに当たり、どう処理するでしょうか。

  1. 有形固定資産の減価償却方法を、定額法から定率法に変えた
  2. 新しい情報により、機械の残りの耐用年数を5年から3年に見直した
  3. 前期末の棚卸資産の数量を数え間違えていたことが分かった
  4. 重要性が増したので、これまで費用処理していた消耗品を資産計上することにした
  5. 営業外費用に表示していた項目を、販売費及び一般管理費に表示することにした
解答と解説を見る
問1会計方針の変更だが、見積りの変更と同じく扱う → 遡及しない
問2会計上の見積りの変更 → 当期と将来に反映する
問3過去の誤謬 → 修正再表示する
問4会計方針の変更に当たらない → 遡及適用しない
問5表示方法の変更 → 過去の財務諸表を組み替える

    4つの区分：まずここから

    1. 方針・表示・見積り・誤謬の処理の違い
    2. さかのぼらないのは見積りの変更だけ

    4. 方針の変更に当たらないもの

    遡及適用：まずここから

    1. 累積的影響額は最も古い期間の期首に
    2. 期首の繰越利益剰余金の修正の計算
    3. 比較情報も作り直す
    4. 変動計算書の累積的影響額の行

    見積りの変更と誤謬：まずここから

    1. 耐用年数の変更は期首帳簿価額を残りで配分
    2. 減価償却方法の変更は見積りの変更と同じ扱い
    3. 最善の見積りなら見積りの変更、見落としなら誤謬
    4. 誤謬は修正再表示

    つなげて覚えるコツ：過去の財務諸表が「そのときのルールと情報で正しく作られていた」なら、見積りを変えても過去は直しません。ルール（方針・表示）を変えたなら、比べられるように過去もそろえます。そもそも誤っていたなら、過去を正しく直します。
